## 订阅

把下面任一地址填到 MWB 的 **设置 → 云端站点库**，然后「导入 → 云端站点库」一键拉取：

```
https://raw.githubusercontent.com/zzyzzy2357/MWB-Sites/main/sites.json
```

国内直连 raw 不稳时用 jsDelivr（带缓存，更新会延迟几分钟）：

```
https://cdn.jsdelivr.net/gh/zzyzzy2357/MWB-Sites@main/sites.json
```

支持填多个地址（换行分隔），软件依次拉取、按域名去重。清单是纯 JSON，
自己 fork 一份改成私藏版也行，填自己仓库的地址即可。

## 提交一个站点

**方式一：在软件里**

站点编辑窗左下角「**分享到公共站点库**」。软件会自动填好名称、地址、类型、充值比例，
打开这里的提交页，点 Submit 就行。

> 首次使用请在 **设置 → 分享提交仓库** 填 `zzyzzy2357/MWB-Sites`。

**方式二：在 GitHub 上**

[新建 issue](https://github.com/zzyzzy2357/MWB-Sites/issues/new/choose) → 选「提交一个中转站」，
按表单填，不填账号密码（也不需要）。

提交后机器人会自动：

1. 只取白名单字段 `name / baseUrl / kind / rechargeRate / note`
2. 校验地址是 http(s) 且域名合法
3. 按域名归一化去重，重复的跳过
4. 合并进 `sites.json`，回帖并关闭 issue

一般一分钟内生效，拉取时带缓存的话最多等几分钟。

## 收录规则

- 只收录**能正常访问**的站点，地址指向 API 根路径（例如 `https://api.example.com`）
- **不收录**：跑路站、纯推广页、需要邀请码才能看的站、赌博/色情等违规内容
- 同一站点多次提交只保留一条；站点改名不会新建条目
- 清单**不排序、不推荐、不评级**，顺序按提交时间，价格请自己在软件里比

## 想下架自己提交的站

开一个 issue 说明要删除的域名即可，或者直接提 PR 从 `sites.json` 删掉对应条目。
